# Jimicut

AI-powered podcast content repurposing tool — upload audio or paste a transcript, get show notes, key takeaways, social posts, YouTube descriptions, LinkedIn posts, and a blog outline.

## Status
Beta. Free tier: 2 full audio→content cycles/day per user, then a waitlist for a future Pro version.

## Run locally
Open `index.html` in a browser — no build step needed.
