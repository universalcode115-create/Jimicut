# CastForge

AI-powered podcast content repurposing tool — paste a transcript, get show notes, key takeaways, social posts, and a blog outline.

## Status
This is an MVP prototype (frontend-only, calls the Claude API for generation). It demonstrates the core "transcript → content" flow. Audio upload + Whisper transcription is planned for the next iteration.

## Run locally
Just open `index.html` in a browser — no build step needed.
